Данные

Импорт CSV / JSON

Файл отправляется в backend, валидируется и создаёт отдельный региональный сценарий. JSON должен содержать region, planning_date, jobs и engineers. CSV использует record_type=job|engineer; один файл — один регион. Для MVP координаты обязательны.

Сценарий дня

Отмена заявки

Состояние заявки сохранится как «Отменена», чтобы в интерфейсе был виден сам факт события. В новый маршрут она не попадёт.
Сценарий дня

Инженер стал недоступен

Работы, завершённые до указанного времени, фиксируются. Остальные заявки возвращаются в планирование с учётом новой доступности инженера; время события сохраняется в журнале.
