# Данные прототипа

## Региональные сценарии

В прототип включены три независимых набора. Backend принимает только их
allowlist; ID заявок и бригад имеют региональный префикс.

| Scenario | Название | Заявок | Бригад |
|---|---|---:|---:|
| `east` | Восток | 66 | 12 |
| `southeast` | Юго-восток | 83 | 12 |
| `southcenter` | Югоцентр | 56 | 11 |

Файлы находятся в `data/scenarios/{scenario}/jobs.json` и
`data/scenarios/{scenario}/engineers.json`. Один набор соответствует одному
региону; назначение между регионами запрещено.

## Поля заявки

| Поле | Тип и единицы | Назначение |
|---|---|---|
| `id` | string | Уникальный ID с префиксом региона. |
| `original_id` | string | ID исходной строки до namespacing. |
| `input_order` | integer | Официальный порядок обработки baseline. |
| `type`, `subtype` | string | Тип и подтип работы. |
| `skill` | enum | Требуемый навык: `connect`, `local`, `emergency`. |
| `priority` | string | Исходная пользовательская пометка срочности. |
| `address` | string | Читаемый адрес. |
| `coords` | `[lat, lon]` | WGS84, десятичные градусы. |
| `window_start`, `window_end` | ISO 8601 | Допустимый интервал начала работы, timezone `+03:00`. |
| `duration_min` | integer, минуты | Длительность обслуживания без времени пути. |
| `required_vehicle` | string или null | Обязательный транспорт, если источник его задаёт. |
| `required_equipment` | object | Требуемое количество оборудования по кодам. |
| `status` | enum | Состояние заявки. В исходных сценариях — `planned`. |
| `district`, `location_id` | string | Район и нормализованная точка. |
| `source_file`, `source_row` | string/integer | Трассировка к исходному набору. |
| `provenance` | object | Происхождение рассчитанных и синтетических полей. |

После расчёта backend добавляет `assigned_engineer_id`, плановые времена,
`assignment_explanation` либо `unassigned_reason`.

## Поля бригады

| Поле | Тип и единицы | Назначение |
|---|---|---|
| `id` | string | ID с префиксом региона. |
| `scenario_id` | enum | Регион бригады. |
| `name` | string | Отображаемое название. |
| `skills` | array | Набор доступных навыков. |
| `vehicle` | enum | `Автомобиль`, `ОТ`, `Велосипед`, `Пешеход`. |
| `shift_start`, `shift_end` | ISO 8601 | Начало и конец смены, timezone `+03:00`. |
| `start_point` | `[lat, lon]` | Старт маршрута в WGS84. |
| `start_address` | string | Читаемый адрес старта. |
| `status` | string | В исходном наборе — `Доступен`. |
| `inventory_start` | object | Инвентарь из подготовленного набора, если задан. |
| `provenance` | object | Происхождение модельных атрибутов. |

Если инвентарь не задан, loader добавляет демонстрационный базовый комплект из
`data/demo_equipment.json`: один `router` и один `tv_box` до начала смены. Это
явное модельное допущение, а не реальные складские данные.

## Справочники

### Классы приоритета

Класс вычисляется из `type` и `skill`:

`emergency > connection > repair_local > additional_order`.

### Статусы

- активные для статического плана: `planned`, `assigned`, `unassigned`,
  `sent`, `en_route`;
- текущие при событии: `en_route`, `in_progress`;
- терминальные: `completed`, `done`, `cancelled`.

### События

| Код | Дополнительные поля |
|---|---|
| `cancel_job` | `job_id` |
| `engineer_unavailable` | `engineer_id`, новый `status` |
| `emergency_job` | `title`, `address`, `coords`, опциональный `required_vehicle` |

Общие поля события: уникальный `event_id`, `event_time`, `base_version` и лимит
решения.

## Единицы и правила интерпретации

- расстояния внутри расчёта — метры, для UI также возвращаются километры;
- время пути, ожидание и обслуживание — целые минуты;
- время решения — миллисекунды;
- дата и время — ISO 8601 с часовым поясом;
- окно ограничивает начало работы; окончание контролируется концом смены;
- время аварии — 80 минут обслуживания плюс фактическое расчётное время пути;
- 20 минут нормативной дороги дополнительно не прибавляются.
