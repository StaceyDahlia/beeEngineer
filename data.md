# Данные прототипа

## Источники и изоляция регионов

В репозитории находятся три встроенных сценария:

| Scenario | Регион | Заявок | Бригад |
|---|---|---:|---:|
| `east` | Восток | 66 | 12 |
| `southeast` | Юго-восток | 83 | 12 |
| `southcenter` | Югоцентр | 56 | 11 |

Файлы лежат в `data/scenarios/{scenario}/jobs.json` и
`data/scenarios/{scenario}/engineers.json`. ID получают префикс сценария;
loader отклоняет чужой префикс или `scenario_id`. Бригады и заявки разных
регионов не смешиваются.

Пользователь может импортировать отдельный регион через CSV или JSON. Импорт
получает уникальный ID `import-*`, проходит те же правила планирования и
хранится в памяти процесса. Рабочий JSON-пример:
[`data/examples/mvp_import.json`](data/examples/mvp_import.json).

## Поля заявки

| Поле | Тип / единицы | Назначение |
|---|---|---|
| `id` | string | Уникальный ID с префиксом сценария. |
| `original_id` | string | ID до добавления регионального namespace. |
| `input_order` | integer | Порядок обработки официальным baseline. |
| `type`, `subtype` | string | Тип и уточнение работы. |
| `skill` | enum | `connect`, `local` или `emergency`. |
| `priority` | string | Исходная пользовательская пометка срочности. |
| `address` | string | Адрес для диспетчера. |
| `coords` | `[lat, lon]` | WGS84, десятичные градусы. |
| `window_start`, `window_end` | ISO 8601 | Допустимый интервал начала работы. |
| `duration_min` | integer, минуты | Обслуживание без времени пути. |
| `required_vehicle` | string или `null` | Обязательный транспорт. |
| `required_equipment` | object | Код оборудования → требуемое количество. |
| `status` | enum | Текущее состояние заявки. |
| `zone` | string или `null` | Необязательная зона для мягкого штрафа перехода. |
| `source`, `provenance` | object/string | Происхождение и модельные допущения. |

После расчёта добавляются `assigned_engineer_id`, плановые времена,
`assignment_explanation` либо `unassigned_reason`, а также класс приоритета.

## Поля бригады

| Поле | Тип / единицы | Назначение |
|---|---|---|
| `id` | string | ID с префиксом сценария. |
| `scenario_id` | string | Региональная принадлежность. |
| `name` | string | Отображаемое имя бригады. |
| `skills` | array | Доступные навыки. |
| `vehicle` | enum | `Автомобиль`, `ОТ`, `Велосипед`, `Пешеход`. |
| `shift_start`, `shift_end` | ISO 8601 | Границы смены с часовым поясом. |
| `start_point` | `[lat, lon]` | Старт маршрута в WGS84. |
| `start_address` | string | Читаемый адрес старта. |
| `status` | string | Доступность бригады. |
| `equipment` | object | Код оборудования → доступное количество. |
| `zone` | string или `null` | Необязательная домашняя зона. |
| `provenance` | object | Происхождение модельных атрибутов. |

Если встроенный набор не задаёт оборудование, loader добавляет явно
документированный demo-комплект из `data/demo_equipment.json`. Это модельное
допущение, а не складской остаток.

## Формат импорта

Файл должен быть UTF-8 и описывать ровно один регион и дату планирования.

JSON содержит `region`, `planning_date`, массивы `jobs` и `engineers`. В CSV
каждая строка содержит общие `region`, `planning_date` и `record_type` со
значением `job` или `engineer`; разделитель — `;`, `,` или tab. Время можно
передавать как `HH:MM` для даты сценария либо как ISO datetime с часовым поясом.

Минимум для заявки: `id`, `skill`, адрес, координаты, окно и положительный
`duration_min`. Минимум для бригады: `id`, непустые `skills`, транспорт,
стартовая точка и корректная смена. ID внутри каждого массива уникальны.

## Справочники

### Приоритеты

Класс вычисляется из типа и навыка:

`emergency > connection > repair_local > additional_order`.

### Статусы

- активные: `planned`, `assigned`, `unassigned`, `sent`, `en_route`;
- текущие при событии: `en_route`, `in_progress`;
- терминальные: `completed`, `done`, `cancelled`.

### События

| Код | Основные поля |
|---|---|
| `cancel_job` | `job_id` |
| `engineer_unavailable` | `engineer_id`, новый `status` |
| `emergency_job` | `title`, `address`, `coords`, опциональные транспорт и оборудование |
| `new_normal_job` | адрес, координаты, навык, окно, длительность и опциональные ограничения |

Общие поля: уникальный `event_id`, `event_time`, `base_version` и
`solve_time_limit_ms`.

## Единицы и интерпретация

- координаты — WGS84 `[latitude, longitude]`;
- расстояние — целые метры, для UI также километры;
- путь, ожидание и работа — целые минуты;
- время решения — миллисекунды;
- дата и время — ISO 8601 с часовым поясом, встроенные данные используют `+03:00`;
- клиентское окно ограничивает начало, конец смены — завершение работы;
- OSRM distance/duration и GeoJSON относятся к одному `matrix_id`;
- нормативные 20 минут дороги поверх рассчитанного пути не добавляются.
